别他妈往 issue 区拉屎

你踩到 bug 了。行，确实烦人。

你打开了 issue 区。很好，地方来得完全正确。

然后表单就摆在你面前——复现步骤、诊断日志、截图——你把同一句「这是一坨屎」复制粘贴进每一个格子，把「我已搜索现有 issue」「我已上传诊断日志」 全部打上勾（一样都没做过），点下提交，还觉得自己刚刚替你妈伸张了正义。

你就一个任务：说清楚发生了什么。你他妈连这个都做不到。

你骗自己的鬼话

「我骂得越狠，他们越知道问题严重。」

你妈是批发的这么玩？怒气携带的信息量是零。你操你妈打了两百个字， 没有一个字说清你点了什么、期望什么、实际发生了什么。把你妈和脏话从你的 issue 里删掉，剩下的内容是：空气。那不叫带情绪的 bug 报告。操你妈的那叫你妈的情绪垃圾。

「这些 bug 弱智到根本不需要描述。」

真弱智的 bug，你妈三十秒就能描述清楚。你他妈连三十秒都拿不出来。 所以现在到底是你妈的智商还是你的智商在及格线上挣扎？

还有那几个验证框——「我已搜索现有 issue」「我已上传诊断日志」。 你全勾了。你一样都没做。你他妈在表单上撒谎撒得比你妈还熟练。

你的暴怒实际达成了什么

  • 你的 issue 一小时内被标记 spam，然后关闭。你献祭全家得到的"正义"得到了伸张。
  • 你被拉黑。下次你真发现了 bug、像个正常人一样来报告，也没人鸟你了。 你把你全家的信用全部押在一场撒泼上了。
  • 关闭不等于消失。issue 区是公开的，社区里的其他人已经围观到了你操你妈的撒泼现场。 评论区在排队骂你全家，截图在群里传着当乐子，你成了这个项目今年最好笑的傻逼展品。
  • 你真踩到的那个 bug——可能是真的，甚至可能挺严重——原地不动。 全世界唯一亲眼见过它的人，选择了操你妈而不是描述。
  • 一个维护者——多半是用爱发电的志愿者——把晚上的时间花在打扫你和你妈的情绪垃圾上，而不是修 bug 上。

你没有「给开发一个教训」。你惩罚的是这个软件的所有其他用户——外加你和你妈自己。 bug 还在那儿，天才。你亲手保证了这一点。

白嫖，还嫖出优越感了

查一下你这个傻逼付了多少钱。零。查一下人家承诺过你什么。开源协议里 用大写字母写着：NO WARRANTY，不提供任何保证。你他妈连这个都看不懂？

别人把自己的下班时间和周末免费送给你用，你的回礼是跑到人家门口拉一泡还顺便操他妈。 白嫖没问题——白嫖本来就是开源的设定。但吃完免费的饭回头骂厨子还带上他全家？ 那你就不是用户了。你是个会打字的脑残。

而且你还是用小号干的。资料非公开，零仓库，零贡献，头像点进去什么都 看不到。你想在公开场合踩别人的作品，同时确保没人能看到你和你糟糕的事迹。 好大的口气，来自一个从来没做出过任何能被批评的东西的废物。

用免费软件，你有权得到的东西只有一样：软件本身。感恩是可选项。 做人是你和你妈存活的必选项。

扎心的对比

你发的 issue： 

[BUG]: 这是一个垃圾应用‼️

复现步骤：
从来没见过 bug 这么多的垃圾！

诊断日志：
从来没见过 bug 这么多的垃圾！

截图：
从来没见过 bug 这么多的垃圾！

☑ 我已搜索现有 issue
☑ 我已上传诊断日志

能让 bug 被修掉的 issue： 

[BUG]: macOS 15 (Apple Silicon) 下载卡在 99%

版本：3.9.6
步骤：添加磁力链接 → 正常下载 → 卡在 99%，界面不卡死
期望：下载完成
实际：一直卡住，重启应用才恢复
日志：已上传 diagnostics.zip —— 14:32 起反复出现 "piece hash mismatch"

最扎心的部分来了：第二种写法里你照样可以。在结尾加一句 「这个问题真的快把我逼疯了，我操」，没人在乎。带复现步骤的暴躁 issue 会被修， 什么都没带的客气 issue 都只能被晾着。你的问题从来不是愤怒—— 是你除了「垃圾」什么都没带。

你在投票选择的未来

去问任何一个退出开源的维护者为什么走。几乎从来不是因为代码。 是因为收件箱。是一封接一封来自匿名小号的、理直气壮的垃圾话， 来的速度比任何人能消化的都快。

你每天离不开的东西——包管理器、终端、下载工具、藏在一切软件里的 那个压缩库——是由少得吓人的一小撮人，下班以后免费撑起来的。

每一个撒泼 issue 都是在投票让他们收手。你不是什么监督者。 你是在放火烧一座免费的图书馆，就因为其中一本书有个错别字—— 烧完还要炫耀你识字。

你可以生气。
你甚至可以操你妈。
但版本号先写。
复现步骤先写。
日志先传。
带着信息的怒气叫反馈。
光有「垃圾」的 issue，叫排泄。
